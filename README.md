- **Responsive Design** - รองรับทุกขนาดหน้าจอ
- **Modern UI/UX** - ดีไซน์สวยงามและทันสมัย
- **Smooth Animations** - แอนิเมชันที่ลื่นไหล
- **Easy to Navigate** - ใช้งานง่าย เข้าถึงข้อมูลได้สะดวก

## 🛠️ Installation

### วิธีที่ 1: อัปโหลดไฟล์ไปยัง GitHub

1. สร้าง repository ใหม่บน GitHub หรือใช้ repo เดิม
2. อัปโหลดไฟล์ทั้งหมด:
   - `index.html`
   - `styles.css`
   - `logo.png` (ไฟล์ที่มีอยู่แล้ว)

### วิธีที่ 2: ใช้ Git Command Line

```bash
# Clone repository ของคุณ
git clone https://github.com/Obiwank107/my-website.git
cd my-website

# วางไฟล์ index.html และ styles.css
# (copy ไฟล์ที่ได้มาจาก Claude)

# Commit และ push
git add .
git commit -m "Update website with new modern design"
git push origin main
```

## 🌐 GitHub Pages Deployment

1. ไปที่ repository settings
2. เลือก **Pages** จากเมนูด้านซ้าย
3. ใน **Source** เลือก `main` branch
4. คลิก **Save**
5. รอสักครู่ เว็บไซต์จะพร้อมใช้งานที่:
   ```
   https://obiwank107.github.io/my-website/
   ```

## 🎨 Customization

### เปลี่ยนสี

แก้ไขใน `styles.css`:

```css
/* พื้นหลัง gradient */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* สีหลัก */
color: #667eea;
```

### เปลี่ยนฟอนต์

แก้ไขใน `styles.css`:

```css
font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
```
